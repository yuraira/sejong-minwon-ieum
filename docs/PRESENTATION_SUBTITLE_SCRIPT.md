## 화면 녹화 체크

1. 로딩 단계가 `개인정보 마스킹 → 승인 KB 검색 → 근거 검증` 순서로 보이게 한다.
2. 근거 부족 폴백과 개인 조회·법적 판단 폴백의 저장 차이를 화면에서 한 번 보여준다.
3. 이음센터에서는 `실패 분석 → 실패 질문 → 후보 작성 → 별도 승인 → ACTIVE` 순서만 시연한다.
4. `9 / 9`, `90%`, `100%`를 말할 때 표본 25문항과 15회 측정 조건을 같은 장면에 표시한다.
5. Windows 11 로컬 검증과 실제 운영 환경을 구분하고, 외부 AI는 기본 비활성임을 자막으로 표시한다.
6. 전국 243개 지자체 확산과 질문당 외부 AI 비용 0원은 검증 완료 수치가 아니라 가설로만 표현한다.

## 자막 스타일

- 한 자막은 최대 두 줄, 한 줄 26자 안팎으로 유지한다.
- 핵심 수치는 화면 하단 자막과 지표 카드에 동시에 표시한다.
- 자막 배경은 반투명 검정, 글자는 흰색, 핵심 수치만 민원이음 파란색을 사용한다.
- 효과음보다 폴백 사유, 보관 기간, 승인 조건을 읽을 시간을 우선한다.
